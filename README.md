# Metro Transaction Reconciliation Platform

An executive-level transaction audit and reconciliation platform. The system ingests multi-channel transaction files (Mobile Apps, Payment Gateways, and AFC Turnstile Gates), maps them to their respective app lines (MumbaiOne, MetroConnect3, ONDC), and uses a fast, set-based classification engine in PostgreSQL to reconcile and audit settlements.

---

## Repository Structure

*   `backend/` - FastAPI application, database schema definitions, transaction parsers, and the classification engine.
*   `frontend/` - React (Vite) dashboard, interactive dropzones with real-time in-memory batch staging overlays, and audited ledger grids.

---

## System Requirements

*   **Python:** 3.10 or higher
*   **Node.js:** 18 or higher
*   **Database:** PostgreSQL 13 or higher (active local instance)

---

## 1. Database Setup

1.  Open your PostgreSQL CLI (`psql`) or query editor (e.g. pgAdmin) and create a fresh database:
    ```sql
    CREATE DATABASE metro_reconciliation;
    ```
2.  The database schemas, staging tables, result outputs, and performance indices are automatically generated by the backend API on startup. No manual SQL DDL execution is required.

---

## 2. Backend Setup (`FastAPI`)

1.  Navigate into the backend directory:
    ```bash
    cd backend
    ```
2.  Create a local virtual environment:
    ```bash
    python -m venv venv
    ```
    *   **Windows (PowerShell):** `.\venv\Scripts\Activate.ps1`
    *   **Mac/Linux:** `source venv/bin/activate`
3.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
4.  Configure environment variables:
    *   Duplicate `.env.example` and rename it to `.env`.
    *   Update your database credentials matching your local PostgreSQL configuration:
        ```env
        # PostgreSQL Database Credentials
        DB_USER=postgres
        DB_PASSWORD=your_secure_password
        DB_HOST=localhost
        DB_PORT=5432
        DB_NAME=metro_reconciliation

        # Server Configuration
        PORT=8000
        HOST=127.0.0.1
        ```
5.  Start the API server:
    ```bash
    python run.py
    ```
    The backend will boot on **[http://localhost:8000](http://localhost:8000)** and automatically run database table builds.

---

## 3. Frontend Setup (`React + Vite`)

1.  Open a new terminal and navigate into the frontend directory:
    ```bash
    cd frontend
    ```
2.  Install npm packages:
    ```bash
    npm install
    ```
3.  Start the Vite local development server:
    ```bash
    npm run dev
    ```
4.  Open your browser and navigate to **[http://localhost:5173](http://localhost:5173)**.

---

## Ingestion & Operation Walkthrough

1.  **Ingestion Hub:** Drop or select files matching your App Line (e.g. MumbaiOne) and Channel (e.g. Mobile, Payment Gateway, or AFC).
2.  **Staging Progress Overlay:** The UI displays real-time network transfer feedback followed by a smooth in-memory staging countdown showing `Staging database: file X of Y successfully staged...`.
3.  **Execute Classification:** Click **Trigger Classification** in the top bar to run the PostgreSQL classification queries and instantly refresh all dashboard charts and metrics.
4.  **Ledger Auditing:** Navigate to the **Reconciliation Ledger** to filter records by system presence (e.g. App, PG, AFC), search for ticket numbers, or revert specific uploaded batches under **Audit Logs**.
